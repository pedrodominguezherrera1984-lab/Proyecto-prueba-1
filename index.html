Una sola imagen Docker optimizada sin dependencias engorrosas. Listo para producción con PostgreSQL y colas Redis. 

# 1. Inicia NEXO con almacenamiento persistente
docker run -d \
  --name nexo \
  -p 5678:5678 \
  -e ENCRYPTION_KEY="generar_clave_segura_aqui" \
  -e WEBHOOK_URL="https://nexo.tu-dominio.com/" \
  -v ~/.nexo_data:/data \
  --restart unless-stopped \
  nexo/nexo:latest

# 2. Accede a tu interfaz gráfica en: http://localhost:5678

¿Tienes dudas? Te las resolvemos

A diferencia de Zapier o Make, NEXO es de código abierto y autoalojable en tu propia infraestructura. No cobramos tarifas abusivas por número de tareas ejecutadas. Además, está pensado específicamente para desarrolladores: permite escribir código JavaScript/Python dentro de cualquier nodo, versionar flujos con Git y crear agentes autónomos de IA usando protocolos modernos como MCP.

Sí. La edición Community es completamente gratuita para uso personal y comercial bajo nuestra licencia de código abierto. Puedes ejecutar tantos flujos, disparadores y datos como soporte tu hardware sin pagar ninguna licencia de software a NEXO.

Absolutamente. Contamos con nodos nativos compatibles con la especificación OpenAI, lo que significa que puedes apuntar a endpoints locales como http://localhost:11434/v1 de Ollama, LM Studio o vLLM con modelos como Llama 3, DeepSeek o Mistral sin que ningún token viaje a internet.

Ofrecemos una herramienta CLI de importación (nexo import --source n8n workflow.json) que convierte automáticamente los nodos estándar y mapeos de variables de n8n a la sintaxis nativa de NEXO con un 95% de compatibilidad automática.

Todas las credenciales se almacenan cifradas en la base de datos utilizando el estándar AES-256-GCM. La clave de cifrado se inyecta mediante variables de entorno en el arranque del contenedor y nunca se guarda en el disco junto con la base de datos. También soportamos integración con HashiCorp Vault y AWS Secrets Manager.
